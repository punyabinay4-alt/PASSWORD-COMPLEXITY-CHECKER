# Password Complexity Checker

A simple Python project that checks password strength based on:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

## Features

- Checks password strength
- Gives a score out of 5
- Provides suggestions for improving weak passwords
- Simple command-line interface

## Requirements

- Python 3.x

## How to Run

```bash
python password_checker.py
